# PDF to JPG — video flow and implementation

Goal: reproduce the supplied 30.67-second reference flow in DocNory's Thai UI and blue visual system. Process documents locally. Keep the existing SSR tool entry and explicit download step.

## Observed flow
- 00–01: existing file workspace; all-tools menu opens with a Convert from PDF group.
- 02–07: dedicated PDF to JPG entry, choose files, native file picker.
- 08–10: file cover/name on left, animated add-files control above; right options panel. Page-to-JPG default; Normal and High image quality. Primary conversion button anchored below.
- 11–12: Extract images selected; quality selector disappears.
- 13–16: switch back to Page-to-JPG; quality choice restored.
- 17: conversion progress screen.
- 18–30: success screen with explicit download and return-to-options controls. Third-party cloud/share/advertising actions are outside DocNory's local-document model.

## Design contract
Use existing SiteNav, FileSourcePicker, Thai Sarabun typography, blue primary buttons, neutral workspace, document cards, and a right sidebar. Mobile stacks settings below the cards; controls remain keyboard reachable and motion respects reduced-motion. SSR intro remains crawlable. Word, PowerPoint, Excel remain clearly unavailable.

States: empty → reading → options → converting → completed; failures return to recoverable options; cancel retains inputs; remove last input returns to empty. A single result downloads as JPG, multiple results as ZIP. Never auto-download. Results can be downloaded repeatedly until reset/navigation.

Constraints: 20 PDFs, 25 MB total, 100 total pages; sequential rasterization; 16 megapixels/8192px per canvas, 500 extracted images and 100 MB encoded output. Normal renders at 150 pixels per PDF inch, High at 300; JPEG density metadata is browser-defined. Transparency becomes white. Extract raster images at decoded native resolution, once per page/object; explain that text/vector drawings are not standalone photos. Destroy PDF.js tasks and revoke Blob URLs on cancellation/reset/disposal.

## Limits
Embedded raster extraction excludes text, vector graphics and stencil masks. Repeated image objects are exported once per page; images reused on different pages can appear more than once. Extraction re-encodes to JPG (not original image bytes), using white for transparency. Browser memory/pixel/output limits produce a recoverable error. Word, PowerPoint and Excel are catalog placeholders, not implemented converters.
